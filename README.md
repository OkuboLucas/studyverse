# 🌌 STUDYVERSE

**Seu espaço para organizar estudos, acompanhar tarefas e evoluir todos os dias.**

O StudyVerse é uma aplicação web em desenvolvimento, criada para centralizar a organização acadêmica em um ambiente digital moderno, intuitivo e com uma identidade visual futurista.

## ✦ Sobre o projeto

A proposta é reunir, em um único lugar, as principais ferramentas para organizar a rotina de estudos, planejar atividades e visualizar a evolução do aprendizado.

O projeto está sendo desenvolvido gradualmente, com foco na aplicação prática dos fundamentos do desenvolvimento web.

## 🚀 Módulos

| Módulo | Descrição |
|---|---|
| 📚 Matérias | Organização dos conteúdos de estudo |
| 📅 Agenda | Planejamento da rotina de estudos |
| ✓ Tarefas | Cadastro e acompanhamento de atividades |
| 📊 Progresso | Visualização da evolução dos estudos |

## 🛠️ Tecnologias

- **HTML5** — estrutura das páginas
- **CSS3** — layout, responsividade e identidade visual
- **JavaScript** — interatividade e funcionalidades
- **Git & GitHub** — versionamento e gerenciamento do código

## 🎨 Identidade visual

A interface segue uma proposta minimalista e futurista, com tema escuro, detalhes em azul e violeta, cartões interativos e uma experiência visual limpa.
